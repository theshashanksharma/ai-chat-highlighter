Get started

From download to first highlight.

The current version is distributed directly, so installation takes a few manual steps.

STEP 01

Download the ZIP

Use the download link above to get the current package from this project's GitHub repository.

STEP 02

Load it in Chrome

Extract the ZIP, visit chrome://extensions, turn on Developer mode, then choose “Load unpacked” and select the folder containing manifest.json.

STEP 03

Try your workflow

Open a supported AI chat and test the extension. If anything looks off, report it through the GitHub repository.
