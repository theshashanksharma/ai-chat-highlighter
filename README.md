# AI Chat Highlighter

A Chrome extension that lets you highlight important insights from ChatGPT, Claude, and Gemini conversations, organize them with colors and notes, and revisit saved knowledge whenever you need it. Built to make AI-powered research and learning easier.

## Features

- Highlight useful passages in supported AI chat interfaces
- Organize insights with colors and notes
- Revisit saved knowledge while researching or learning
- Cloud-sync capabilities in supported builds

## Install for testing

1. Download a project ZIP from the repository.
2. Extract it to a folder on your computer.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted extension folder.
